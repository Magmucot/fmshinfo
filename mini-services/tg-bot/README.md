# Telegram-бот «СУНЦ Инфо»

Неофициальный бот ученика СУНЦ НГУ (ФМШ): меню столовой, звонки, расписание
класса с учётом групп, погода в Академгородке, новости, дежурства, ночные
вожатые и контакты школы. Данные получает от внутреннего API-источника
(`http://localhost:3000/api/...`); публичный веб-интерфейс для работы бота не нужен.

## Команды

| Команда | Что делает |
|---|---|
| `/start`, `/help` | приветствие, список команд и быстрая Reply-клавиатура |
| `/now` | ⚡ статус прямо сейчас: текущая пара, столовая, погода, дежурство |
| `/menu` | меню столовой, рейтинг каждого блюда и кнопка оценки 1–5 ⭐ |
| `/menu 01.09.2026` | меню на конкретную дату |
| `/canteen` | 🍱 график смен и время приёмов пищи со 2 сентября (из rasp.jpg) |
| `/canteen 10-1` | персональное расписание столовой для конкретного класса |
| `/schedule` | расписание класса на сегодня (с типами: Лекция, Семинар, Спецкурс) |
| `/schedule 10-2` | расписание любого класса с инлайн-кнопками дней недели |
| `/tomorrow` | расписание на завтра |
| `/setclass 10-1` | 👤 сохранить свой класс по умолчанию для всех команд |
| `/myclass` | посмотреть сохранённый класс |
| `/find Горшков` | 🔍 найти расписание преподавателя или аудитории (`/find 2_10`) |
| `/bells` | расписание звонков по парам |
| `/events` | ближайшие мероприятия (из Google-таблицы школы) |
| `/events 10-1` | мероприятия для класса 10-1 (включая многоклассовые и общие) |
| `/weather` | погода сейчас + прогноз на 3 дня |
| `/news` | 6 последних новостей школы |
| `/duty` | дежурства на сегодня |
| `/counselors` | ночные вожатые на сегодня |
| `/info` | адрес, e-mail и телефоны школы |
| `/stats` | 📊 обезличенная статистика школы (топ классов, параллели, без личных данных) |

### 🛡️ Безопасность и защита от DDoS (Anti-Flood)
1. **Защита от флуда:** автоматический ограничитель запросов (Sliding Window Rate Limiter). Ограничивает частые клики (>3 запросов в 2 секунды, интервал <350мс). При превышении включается временный кулдаун (15с, 45с, 120с), спам-сообщения отсекаются на уровне middleware без нагрузки на API и диск.
2. **Кэширование API:** ответы API кэшируются в памяти (TTL 30 секунд); одинаковые одновременные запросы объединяются, а кэш ограничен 128 ключами.
3. **Защита персональных данных:** для обычных пользователей в `/stats` и других командах полностью скрыты Telegram ID, `@юзернеймы` и история действий.

### 🔑 Команды администратора (требуется верификация)
| Команда | Описание |
|---|---|
| `/auth <секрет>` | Авторизация администратора (пароль берется из `ADMIN_KEY` в `.env`, сообщение с паролем удаляется автоматически) |
| `/logs [N]` | Просмотр последних N строк системного журнала (`logs/bot.log`) |
| `/stats` | Расширенная статистика с недавней активностью учеников |
| `/unauth` | Завершение сессии администратора |

**Удобства бота:**
- **Быстрая клавиатура (ReplyKeyboard):** кнопки внизу чата для мгновенного доступа к меню, расписанию, столовой, звонкам и мероприятиям.
- **Интерактивные кнопки (InlineKeyboard):** переключение смен питания, дней недели в расписании, дат в меню.
- **Рейтинг еды:** один голос 1–5 ⭐ на блюдо от пользователя; оценку можно поменять. Среднее и число голосов видны в меню, а файл `food_ratings.json` хранится в `BOT_DATA_DIR` с правами `600`.
- **Точные типы занятий:** различаются лекции, семинары, спецкурсы и лабораторные работы.
- **Интеграция rasp.jpg:** полная раскладка по сменам (1, 2, 3 смены, дежурные, опоздавшие, будни и выходные дни).

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather): `/newbot` → получите токен.
2. Запустите сервис с токеном:

```bash
cd mini-services/tg-bot
TELEGRAM_BOT_TOKEN=123456:ABC-DEF... bun run dev
```

Без токена сервис стартует в «спящем» режиме: health-сервер работает,
бот не подключается к Telegram (удобно для разработки).

- Порт: **3003** (health: `http://localhost:3003/health`)
- Горячая перезагрузка: `bun --hot` (перезапускается при изменении файлов)
- Переменная `PORTAL_API` (по умолчанию `http://localhost:3000`) — адрес API портала

## Архитектура

```
Telegram ←→ grammY long polling
                │
                ▼
        mini-services/tg-bot/index.ts
                │ fetch (server-to-server)
                ▼
  Next.js API портала (порт 3000) — /api/menu, /api/schedule, ...
                │
                ▼
     sesc.nsu.ru · table-sesc.nsu.ru · Open-Meteo
```

Форматирование сообщений — Telegram HTML; все данные экранируются,
длинные операции сопровождаются «typing…».

### Ключ администратора

`ADMIN_KEY` в окружении бота нужен для `/auth`; встроенного пароля нет. Ключ портала нужен отдельно, только если через его административные API изменяются дежурства или вожатые. Профили, статистика и рейтинг больше не синхронизируются с веб-порталом.

## Production на сервере

Основной серверный запуск — [`deploy/start-nohup.sh`](../../deploy/start-nohup.sh): он поднимает внутренний API в фоне, ждёт готовности и затем запускает бота. Команды: `start`, `stop`, `restart`, `status`. Systemd остаётся альтернативой: [инструкция](../../deploy/systemd/README.md).

Скрипт `run-production.sh` запускает Bun без hot reload и требует `TELEGRAM_BOT_TOKEN`, `ADMIN_KEY`, `PORTAL_API`. Профили, рейтинг и логи хранятся вне кода; если каталоги не заданы, для `nohup` используются `~/.local/share/sunc-tg-bot` и `~/.local/state/sunc-tg-bot`. SIGTERM сохраняет данные, ошибки старта завершают процесс для автоперезапуска.

Бот получает расписание и меню от портала. Если `PORTAL_API=http://127.0.0.1:3000`, запустите также user-level службу портала `sunc-portal`; её unit и инструкция находятся рядом с bot unit.
