# Telegram-бот «СУНЦ Инфо»

Неофициальный бот ученика СУНЦ НГУ (ФМШ): меню столовой, звонки, расписание
класса с учётом групп, погода в Академгородке, новости, дежурства, ночные
вожатые и контакты школы. Данные берёт из API основного портала
(`http://localhost:3000/api/...`), поэтому бот всегда синхронен с сайтом.

## Команды

| Команда | Что делает |
|---|---|
| `/start`, `/help` | приветствие и список команд |
| `/menu` | меню столовой на сегодня (КБЖУ + итоги дня) |
| `/menu 01.09.2026` | меню на конкретную дату |
| `/bells` | расписание звонков по парам |
| `/schedule` | расписание класса 10-1 на сегодня |
| `/schedule 10-2` | расписание любого класса |
| `/tomorrow` | расписание на завтра |
| `/weather` | погода сейчас + прогноз на 3 дня |
| `/news` | 6 последних новостей школы |
| `/duty` | дежурства на сегодня |
| `/counselors` | ночные вожатые на сегодня |
| `/info` | адрес, e-mail и телефоны школы |

**Группы:** если несколько уроков идут в одно время, класс разделён на группы —
бот помечает такие слоты «класс делится на N группы» и перечисляет каждый
вариант отдельно (предмет, кабинет, учитель).

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather): `/newbot` → получите токен.
2. Запустите сервис с токеном:

```bash
cd mini-services/tg-bot
TELEGRAM_BOT_TOKEN=123456:ABC-DEF... bun run dev
```

Без токена сервис стартует в «спящем» режиме: health-сервер работает,
бот не подключается к Telegram (удобно для разработки).

- Порт: **3003** (health: `http://localhost:3003/health`)
- Горячая перезагрузка: `bun --hot` (перезапускается при изменении файлов)
- Переменная `PORTAL_API` (по умолчанию `http://localhost:3000`) — адрес API портала

## Архитектура

```
Telegram ←→ grammY long polling
                │
                ▼
        mini-services/tg-bot/index.ts
                │ fetch (server-to-server)
                ▼
  Next.js API портала (порт 3000) — /api/menu, /api/schedule, ...
                │
                ▼
     sesc.nsu.ru · table-sesc.nsu.ru · Open-Meteo
```

Форматирование сообщений — Telegram HTML; все данные экранируются,
длинные операции сопровождаются «typing…».
